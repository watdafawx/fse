## FSE 0.16.3

fse-std 0.6.3 (bundled):

- A server-wide default theme: the map setting "Themes: default theme" (or `remote.call("fse-std", "set_default_theme", name)`).
  Players who haven't picked a theme follow it; each player's own pick still wins.
- The theme window, theme names and colour names are translatable (`locale/<lang>/fse-std.cfg`).
